# Message collection sheet

Thank you for helping. We are testing how well a student planner app understands what people type. Your
messages become a **test set**, so please write them the way you really would — short, long, lazy spelling, mixed
English and Urdu, whatever is natural for you.

## Before you start

- **Don't read the app's code**, and don't look at other people's answers first.
- **No real personal data.** Use made-up names, places and numbers. Never your phone number, CNIC or address.
- For each situation below, write **3 to 5 messages** you might send to the app.
- Write each message on its own line starting with `- `.
- Put English messages under **English** and Roman Urdu messages (Urdu in English letters, e.g. "kal subah 9 baje
  gym jana hai") under **Roman Urdu**. Leave a list empty if you don't write that way.
- Don't change the lines that start with `<!--`; they tell the script which situation it is.
- When you're done, save the file as `collect-<your initials>.md` and send it back.
