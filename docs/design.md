# Design Guidelines

## Principles

-   Simple
-   Clean
-   Productivity focused

## Screens

-   Login
-   Signup
-   Dashboard
-   Task List
-   Chat Assistant
-   Voice Assistant
-   Profile
-   Settings

## UI Rules

-   Use reusable components.
-   Maintain consistent spacing.
-   Provide clear feedback.
-   Do not expose technical AI details.
