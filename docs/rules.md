# Development Rules

## Coding

-   Use TypeScript.
-   Keep modules separated.
-   Use reusable components.
-   Follow clean architecture.

## AI Rules

-   Never call AI APIs directly from mobile.
-   Validate AI output.
-   Keep AI providers replaceable.

## Task Rules

-   Chat and voice use same parser.
-   Clarity score is internal only.
-   Never show technical AI scores.

## Testing

Every module requires: - Unit testing - Integration testing - Regression
testing
